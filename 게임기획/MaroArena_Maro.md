# 멀티 사격 게임

## 경기

- Cocos2d-x 4.0으로 만든 Windows 탑뷰 팀 슈팅 게임이다. 캐릭터마다 실제 참가자 한 명이 조작한다.
- 프리셋은 1vs1, 2vs2, 3vs3, 4vs4다. 커스텀 경기에서는 2~4팀을 만들고 팀마다 1~4명을 배치한다. 3팀에 1명씩 배치하면 1vs1vs1이 된다.
- 아군끼리는 탄 피해를 주지 않는다. 마지막까지 살아남은 팀이 승리한다. 쓰러진 플레이어는 경기 결과가 나올 때까지 관전할 수 있다.
- 캐릭터는 팀 색상의 원형 실루엣, 총구, 체력 바로 구분한다. 두 엄폐물이 이동 경로와 탄을 차단한다.

## 방 만들기와 참가

1. Windows 앱을 실행한다. 방장은 메인 화면에서 팀 구성을 선택하고 **방 만들기**를 누른다.
2. 같은 로컬 네트워크의 참가자는 **경기 준비**에 표시된 **방 코드**를 입력하고 **방 참여**를 누른다.
3. 참가자 자리는 팀 순서에 따라 채워진다. 모든 자리가 차면 방장이 메인 화면에서 **경기 시작**을 누른다. 참가자마다 WASD 또는 MOBA 조작을 따로 선택할 수 있다.
4. 경기 중 참가자가 나가면 해당 캐릭터는 탈락 처리된다. 방장이 나가면 연결이 종료된다.

모든 참가자는 같은 버전의 앱을 사용한다.

## 조작

메인 화면에서 방을 만들거나 참가할 수 있다. 경기 중 **Esc → 메인으로**를 누르면 연결을 유지한 채 메인으로 돌아간다. 경기가 진행 중이면 **계속하기**로 복귀할 수 있다. **Esc** 설정에서 조작 방식, 음량, 전체 화면, 화면 흔들림과 FPS 표시를 바꿀 수 있다.

| 동작 | WASD | MOBA |
| --- | --- | --- |
| 이동 | W, A, S, D | 좌클릭으로 지정한 지점까지 이동 |
| 조준 | 마우스 커서 | 마우스 커서 |
| 사격 | 좌클릭 | Q |
| 방어 | 우클릭 유지 | E 유지 |
| 패링 | 우클릭 + 좌클릭 | Shift |

방어 중에는 이동 속도가 줄고 정면에서 들어오는 탄의 피해가 감소한다. 패링은 0.22초 동안 정면 탄을 반사하며 기본 재사용 대기시간은 0.9초다. 캐릭터의 자원은 체력뿐이며 기본 최대 체력은 100이다.

## 레벨과 증강

1. 1레벨에서 시작해 6레벨까지 성장한다. 경기 시작 시 1레벨 증강을 먼저 선택한다.
2. 적을 한 명 처치하거나 직전 레벨업 후 경기 시간이 15초 지나면 한 단계 오른다.
3. 매 레벨마다 서로 다른 후보 3개 중 하나를 선택한다. 버튼을 클릭하거나 숫자 키 1~3으로 고른다. 증강을 받을 참가자가 모두 선택할 때까지 경기 시간이 멈춘다.
4. 기본 증강으로 대미지, 공격 속도, 체력, 이동, 방어를 강화한다. 전투 증강으로 산탄총, 폭발탄, 도탄, 관통탄, 냉각탄, 연속 패링, 불사조를 얻을 수 있다.
5. 산탄총에 폭발탄을 더하면 각 산탄이 충돌할 때 폭발한다. 폭발 증폭은 폭발탄과 처치 폭죽을 강화하고, 빙결 파쇄는 냉각탄으로 느려진 적에게 추가 피해를 준다. 연속 패링은 탄을 반사하면 패링을 즉시 다시 쓸 수 있게 한다.

## 실행과 소스 빌드

- Windows에서 `Release/MaroArena.exe`를 연다. 다른 PC로 옮길 때는 DLL과 `Assets`가 들어 있는 `Release` 폴더 전체를 복사한다. 실행하려면 Microsoft Visual C++ 재배포 가능 패키지(x86)가 설치되어 있어야 한다.
- 소스를 빌드하려면 Visual Studio의 C++ 데스크톱 개발 워크로드와 CMake 도구를 설치한 뒤, 프로젝트 폴더에서 아래 명령을 실행한다.

```powershell
powershell -ExecutionPolicy Bypass -File .\Build_Maro.ps1 -Run
```

스크립트는 Cocos2d-x 4.0과 Windows용 외부 라이브러리를 내려받는다. 이미 설치한 SDK를 사용하려면 `-CocosRoot`에 SDK 경로를 전달한다. 빌드가 끝나면 콘솔에 실행 파일 경로가 표시된다.
